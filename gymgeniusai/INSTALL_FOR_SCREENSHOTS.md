# Install Build for Screenshots 📱

You have Build 10 (Version 1.0.0) ready! Here's how to install it:

## ✅ OPTION 1: TestFlight (Easiest)

1. **Check if you're invited:**
   - I can see "INVITES: 1" in your dashboard
   - The build is in "TE Team (Expo)" group

2. **On your iPhone:**
   - Open the **TestFlight** app (download from App Store if needed)
   - Check if "KINETIC FLOW AI" appears in your apps
   - If yes: Tap "Install" → Open app → Take screenshots!

3. **If you don't see it in TestFlight:**
   - You might need to add yourself to the TestFlight group
   - Go to your Expo dashboard → Testers section
   - Add your Apple ID email to the "TE Team (Expo)" group

---

## ✅ OPTION 2: Direct Install Link

1. **In Expo Dashboard:**
   - Go to the build details for Build 10
   - Look for "Install" or "Download" button
   - Click it to get an installation link

2. **On your iPhone:**
   - Open the link in Safari
   - Follow prompts to install
   - You may need to trust the developer certificate in Settings

---

## ✅ OPTION 3: Build a Quick Development Build

If TestFlight doesn't work, build a development build specifically for screenshots:

```bash
eas build --profile development --platform ios
```

This will create a build you can install directly on your device.
